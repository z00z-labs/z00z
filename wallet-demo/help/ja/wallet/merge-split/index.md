# ウォレット：結合

[TOC]

## アプリ画面 {#current-view}

![ウォレットの結合画面](help/assets/en/wallet-merge.png)

この画像は現在の Demo の結合画面から取得されています。

## 概要 {#overview}

結合は、互換性のある2つ以上の機密アセット断片を1つの出力にまとめます。出力は同じ `definition_id` と基本 `serial_id` を維持し、その金額は選択した入力の合計と等しくなります。結合は出力の構成を変えますが、アセット定義を変更したり供給量を作成したりしません。

候補は定義とシリーズの両方でグループ化されます。表示シンボルが同じでも、異なるグループの断片を結合することはできません。

## この画面の使い方 {#how-to-use-this-view}

1. アプリケーションヘッダーで有効なウォレットとネットワークを確認します。
2. **結合**を選択します。
3. 1つの互換グループから利用可能な断片を2つ以上選択します。
4. 選択した入力数、出力合計、定義、シリーズを確認します。
5. **結合をプレビュー**を選択し、各入力と提案された単一出力を確認します。
6. 認可、手数料、送信、照合を再確認できるネイティブウォレットでのみ続行します。

## 用語と操作 {#terms-and-controls}

| 用語または操作 | 説明 |
| --- | --- |
| 定義 ID | アセット種別とポリシーの不変識別子です。選択したすべての入力が同じ値を持つ必要があります。 |
| シリアル ID | 基本発行シリーズです。すべての入力と結合後の出力は同じシリーズを維持します。 |
| アセット ID | 具体的な機密出力の識別子です。互換性のある断片でも異なるアセット ID を持つ場合があります。 |
| 互換グループ | 定義 ID とシリアル ID が同じ利用可能な断片です。 |
| ロック済み | 断片は文脈表示されますが選択できません。 |
| 出力合計 | 別個のネイティブ手数料ポリシーが適用される前の、選択した入力の正確な合計です。 |
| 結合をプレビュー | 入力と提案出力を示す確認専用の意図です。署名も送信もしません。 |

## 安全性と制限 {#safety-and-limits}

- このインターフェースは異なる定義や基本シリーズをまたいで結合しません。
- ネイティブウォレットは、古い画面に以前表示されていても、ロック済み、使用済み、凍結、焼却、没収、その他利用不可の入力を拒否する必要があります。
- 断片を結合すると、関連する入力を相関しやすくなる場合があります。反復的または強いパターンを持つ操作の前にプライバシーへの影響を確認してください。
- JavaScript Demo は公開テストデータを使用し、プレビューで停止します。鍵の保持、所有権の証明、署名の作成、手数料の請求、パッケージの送信、不確実な結果の照合は行いません。
- 現在の `wallet.asset.merge_assets` helper は互換性のための表面であり、正規の台帳照合権限を主張しません。ネイティブ統合では、権限あるウォレットトランザクション経路を通じて確認する必要があります。
