![Экран объединения в кошельке](help/assets/en/wallet-merge.png)

## Обзор {#overview}

Объединение собирает два или более совместимых конфиденциальных фрагмента актива в один выход. Выход сохраняет те же `definition_id` и базовый `serial_id`, а его сумма равна сумме выбранных входов. Операция меняет структуру выходов, но не определение актива и не создаёт дополнительную эмиссию.

Кандидаты группируются одновременно по определению и серийному выпуску. Фрагменты из разных групп нельзя объединить, даже если у них одинаковый отображаемый символ.

## Как использовать этот экран {#how-to-use-this-view}

1. Проверьте активный кошелёк и сеть в заголовке приложения.
2. Выберите **Объединить**.
3. Выберите не менее двух доступных фрагментов из одной группы совместимости.
4. Проверьте число выбранных входов, общую сумму выхода, определение и серийный выпуск.
5. Выберите **Предпросмотр объединения** и проверьте каждый вход и предлагаемый единый выход.
6. Продолжайте только в нативном кошельке, который может повторно проверить авторизацию, комиссии, отправку и сверку результата.

## Термины и элементы управления {#terms-and-controls}

| Термин или элемент | Объяснение |
| --- | --- |
| ID определения | Неизменяемый идентификатор типа актива и его политики. Все выбранные входы должны иметь одинаковое значение. |
| Серийный ID | Базовая серия выпуска. Все выбранные входы и объединённый выход сохраняют одну серию. |
| ID актива | Идентификатор конкретного конфиденциального выхода. У совместимых фрагментов ID активов могут различаться. |
| Группа совместимости | Доступные фрагменты с одинаковыми ID определения и серийным ID. |
| Заблокирован | Фрагмент виден для контекста, но выбрать его нельзя. |
| Общий выход | Точная сумма выбранных входов до применения отдельной политики комиссии нативного кошелька. |
| Предпросмотр объединения | Намерение только для проверки, показывающее входы и предлагаемый выход; оно ничего не подписывает и не отправляет. |

## Безопасность и ограничения {#safety-and-limits}

- Этот интерфейс никогда не объединяет разные определения или базовые серии.
- Нативный кошелёк должен отклонить заблокированные, потраченные, замороженные, сожжённые, оштрафованные или иначе недоступные входы, даже если устаревший экран ранее показывал их.
- Объединение фрагментов может упростить сопоставление связанных входов. Оцените влияние на приватность перед повторяющимися или шаблонными операциями.
- JavaScript Demo использует публичные тестовые данные и останавливается на предпросмотре. Оно не хранит ключи, не доказывает владение, не создаёт подписи, не списывает комиссии, не отправляет пакет и не сверяет неопределённый результат.
- Текущий помощник `wallet.asset.merge_assets` является поверхностью совместимости и не заявляет канонические полномочия сверки реестра. Нативная интеграция должна направлять подтверждение через авторитетный путь транзакции кошелька.
