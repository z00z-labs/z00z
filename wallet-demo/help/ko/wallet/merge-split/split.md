# 지갑: 분할

[TOC]

## 앱 화면 {#current-view}

![지갑 분할 화면](help/assets/en/wallet-split.png)

이 이미지는 현재 Demo 분할 화면에서 캡처되었습니다.

## 개요 {#overview}

분할은 기밀 자산 조각 하나를 소비해 두 개 이상의 출력을 준비합니다. 각 출력은 원본의 `definition_id`와 기본 `serial_id`를 유지하며, 모든 양수 출력 금액의 합은 입력 금액과 정확히 같아야 합니다. 분할은 출력 구성을 바꾸지만 자산 정의를 변경하거나 공급량을 생성하지 않습니다.

각 결과 조각은 동일한 발행 시리즈에 속하면서도 자체적인 구체적 출력 식별자를 갖습니다.

## 이 화면 사용 방법 {#how-to-use-this-view}

1. 애플리케이션 헤더에서 활성 지갑과 네트워크를 확인합니다.
2. **분할**을 선택합니다.
3. 사용 가능한 원본 조각 하나를 선택합니다.
4. 두 개에서 여덟 개 사이의 양수 출력 금액을 입력합니다.
5. **보존**이 **정확함**으로 표시되는지 확인합니다.
6. **분할 미리보기**를 선택하고 원본과 제안된 각 출력을 검토합니다.
7. 권한, 수수료, 제출 및 조정을 다시 확인할 수 있는 네이티브 지갑에서만 계속합니다.

## 용어 및 제어 {#terms-and-controls}

| 용어 또는 제어 | 설명 |
| --- | --- |
| 원본 자산 | 제안된 분할에서 소비되는 하나의 사용 가능한 조각입니다. |
| 정의 ID | 자산 유형과 정책의 변경 불가능한 식별자입니다. 각 출력은 원본 정의를 유지합니다. |
| 시리얼 ID | 기본 발행 시리즈입니다. 각 출력은 원본 시리즈를 유지합니다. |
| 출력 배분 | 제안된 출력에 할당하는 두 개에서 여덟 개 사이의 양수 금액입니다. |
| 보존 | 입력 금액과 모든 출력 금액 합계의 정확한 일치입니다. |
| 출력 추가 | 인터페이스 제한까지 양수 배분 필드를 하나 더 추가합니다. |
| 분할 미리보기 | 원본과 제안된 출력을 보여 주는 검토 전용 의도이며, 서명하거나 제출하지 않습니다. |

## 안전 및 제한 {#safety-and-limits}

- 분할은 원본 정의나 기본 시리즈를 변경하지 않습니다.
- 0, 음수, 과도한 금액 또는 보존되지 않는 배분은 거부해야 합니다.
- 네이티브 지갑은 이후 잠김, 사용됨, 동결, 소각, 삭감 또는 기타 사용 불가 상태가 된 원본을 거부해야 합니다.
- 반복적이거나 비정상적으로 패턴화된 배분은 관련 출력을 더 쉽게 연관 지을 수 있습니다.
- JavaScript Demo는 공개 테스트 데이터를 사용하며 미리보기에서 중단됩니다. 키를 보관하거나 소유권을 증명하거나 서명을 만들거나 수수료를 부과하거나 패키지를 제출하거나 불확실한 결과를 조정하지 않습니다.
- 현재 `wallet.asset.split_asset` helper는 호환성 표면이며 정식 원장 조정 권한을 주장하지 않습니다. 네이티브 통합은 권한 있는 지갑 트랜잭션 경로를 통해 확인을 처리해야 합니다.
