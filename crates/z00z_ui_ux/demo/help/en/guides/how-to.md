# How to use the demo

[TOC]

## Overview

Learn the navigation model and the safe way to explore planned Z00Z wallet flows.

## How to use this guide

### Navigate on desktop and mobile
- Open a first-level accordion in the main menu, then select a workspace such as Wallet, Telemetry, or dApps.
- Use the inner vertical navigation on desktop and the same workspace options as top tabs on mobile.

### Explore roadmap exchange flows
- Open dApps, then choose Swap or Exchange to review the proposed non-custodial flow.
- The demo does not execute a trade, connect a provider, move funds, or accept wallet secrets.

### Keep the boundary clear
- A future packaged wallet must revalidate every quote, permission, signature, fee, and destination.
- Ethereum, Liquity BOLD, solver, and cross-chain material is published only in its relevant Help article and must not be presented as a shipped capability unless the current interface provides verified execution evidence.

## Safety and limits

Treat the interface status shown by the current application as authoritative. Never share a seed phrase, private key, recovery material, or other wallet secret while following Help instructions.
