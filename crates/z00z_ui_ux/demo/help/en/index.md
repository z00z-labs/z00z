## Overview

Help is the standalone, searchable guide for the Z00Z Wallet Demo. Its menu is
built from the `_meta.yaml` files stored beside the articles, so the visible
sections, article order, and available languages follow the checked-in Help
content.

Opening Help from a screen selects the matching article. Opening Help from the
main menu starts here.

## How to use this view

1. Choose a section in the left menu. On mobile, open the menu button first.
2. Expand a section and select the article for the screen or task you want to
   understand.
3. Use Search or `Ctrl K`/`⌘ K` to find terms across every article.
4. Change language without losing the selected topic.
5. Follow the article's safety and availability notes before treating a Demo
   result as a completed wallet or network operation.

## Terms and controls

| Term or control | Explanation |
| --- | --- |
| Contents | Metadata-ordered tree containing every published Help article. |
| Search | Finds matching article titles and body text in the selected language. |
| Language | Changes the Help catalogue while preserving the current topic when that topic exists. |
| App View | Screenshot of the Demo screen described by an article. |
| Current topic | Article selected by a contextual Help action, search result, or menu link. |

## Safety and limits

- Help is packaged content; it does not need wallet keys, a wallet session, or
  private transport data.
- Screens marked as concept, target, unavailable, or local-only do not prove
  that a native service executed the described action.
- Never paste a seed phrase, private key, recovery material, or sensitive
  message into an issue report or third-party page opened from Help.
