## この画面の使い方 {#current-view}
- 64 KiB 以下の `AssetPkgWire` JSON パッケージを選択します。
- ウォレット、ネットワーク、クラス、金額、シリアル ID、ドメイン、状態フラグ、所有者バインドを確認します。
- **アセットをインポート**を選択します。暗号、所有権、リプレイ、claim 競合はネイティブウォレットが検証します。

## ローカルで安全な動作
- `secret` フィールドは禁止され、絶対ファイルパスは保存も RPC 送信もされません。
- 結果は新規インポート、既存アセット、明示的な `IMPORT_*` 理由を区別します。
