# ウォレット：分割

[TOC]

## アプリ画面 {#current-view}

![ウォレットの分割画面](help/assets/en/wallet-split.png)

この画像は現在の Demo の分割画面から取得されています。

## 概要 {#overview}

分割は1つの機密アセット断片を消費して、2つ以上の出力を準備します。各出力は元の `definition_id` と基本 `serial_id` を維持し、すべての正の出力金額の合計が入力金額と正確に一致する必要があります。分割は出力の構成を変えますが、アセット定義を変更したり供給量を作成したりしません。

生成される各断片は、同じ発行シリーズの一部でありながら、固有の具体的な出力 ID を受け取ります。

## この画面の使い方 {#how-to-use-this-view}

1. アプリケーションヘッダーで有効なウォレットとネットワークを確認します。
2. **分割**を選択します。
3. 利用可能な元の断片を1つ選択します。
4. 2個から8個の正の出力金額を入力します。
5. **保存**が **正確** と表示されることを確認します。
6. **分割をプレビュー**を選択し、元の断片と提案された各出力を確認します。
7. 認可、手数料、送信、照合を再確認できるネイティブウォレットでのみ続行します。

## 用語と操作 {#terms-and-controls}

| 用語または操作 | 説明 |
| --- | --- |
| 元のアセット | 提案された分割で消費される、利用可能な1つの断片です。 |
| 定義 ID | アセット種別とポリシーの不変識別子です。各出力は元の定義を維持します。 |
| シリアル ID | 基本発行シリーズです。各出力は元のシリーズを維持します。 |
| 出力配分 | 提案出力に割り当てる2個から8個の正の金額です。 |
| 保存 | 入力金額とすべての出力金額の合計が正確に等しいことです。 |
| 出力を追加 | インターフェース上限まで、正の配分フィールドを1つ追加します。 |
| 分割をプレビュー | 元の断片と提案出力を示す確認専用の意図です。署名も送信もしません。 |

## 安全性と制限 {#safety-and-limits}

- 分割は元の定義や基本シリーズを変更しません。
- ゼロ、負、過大、または金額を保存しない配分は拒否する必要があります。
- ネイティブウォレットは、後からロック済み、使用済み、凍結、焼却、没収、その他利用不可になった元の断片を拒否する必要があります。
- 反復的または異常にパターン化された配分は、関連出力を相関しやすくする場合があります。
- JavaScript Demo は公開テストデータを使用し、プレビューで停止します。鍵の保持、所有権の証明、署名の作成、手数料の請求、パッケージの送信、不確実な結果の照合は行いません。
- 現在の `wallet.asset.split_asset` helper は互換性のための表面であり、正規の台帳照合権限を主張しません。ネイティブ統合では、権限あるウォレットトランザクション経路を通じて確認する必要があります。
