# 钱包：合并

[TOC]

## 应用视图 {#current-view}

![钱包合并视图](help/assets/en/wallet-merge.png)

此图像来自当前 Demo 的合并视图。

## 概览 {#overview}

合并会将两个或更多兼容的机密资产片段组合成一个输出。该输出保留相同的 `definition_id` 和基础 `serial_id`，金额等于所选输入的总和。合并只改变输出的组织方式，不会更改资产定义或创建新的供应量。

候选片段会同时按定义和系列分组。即使显示符号相同，不同组中的片段也不能合并。

## 如何使用此视图 {#how-to-use-this-view}

1. 在应用标题栏中确认当前钱包和网络。
2. 选择 **合并**。
3. 从同一个兼容组中选择至少两个可用片段。
4. 检查所选输入数量、总输出金额、定义和系列。
5. 选择 **预览合并**，检查每个输入和拟议的单一输出。
6. 仅在能够重新检查授权、费用、提交和对账的原生钱包中继续。

## 术语和控件 {#terms-and-controls}

| 术语或控件 | 说明 |
| --- | --- |
| 定义 ID | 资产类型及其策略的不可变标识符。所有所选输入必须共享此标识符。 |
| 系列 ID | 基础发行系列。所有输入和合并后的输出都保留同一系列。 |
| 资产 ID | 某个具体机密输出的标识符。兼容片段可以具有不同的资产 ID。 |
| 兼容组 | 定义 ID 和系列 ID 相同的可用片段。 |
| 已锁定 | 片段仍显示为上下文，但无法选择。 |
| 总输出 | 应用任何单独的原生费用策略之前，所选输入的精确总和。 |
| 预览合并 | 仅供检查的意图，显示输入和拟议输出；不会签名或提交。 |

## 安全性和限制 {#safety-and-limits}

- 此界面不会跨不同定义或基础系列进行合并。
- 原生钱包必须拒绝已锁定、已花费、已冻结、已销毁、已罚没或以其他方式不可用的输入，即使过时的屏幕曾显示过这些输入。
- 合并片段可能使相关输入更容易被关联。执行重复或具有明显模式的操作前，请检查其隐私影响。
- JavaScript Demo 使用公开测试数据，并在预览阶段停止。它不持有密钥、不证明所有权、不创建签名、不收取费用、不提交数据包，也不对不确定结果进行对账。
- 当前 `wallet.asset.merge_assets` helper 是兼容性接口，不声明拥有规范账本对账权限。原生集成必须通过权威的钱包交易路径进行确认。
