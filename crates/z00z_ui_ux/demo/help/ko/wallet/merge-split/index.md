# 지갑: 병합

[TOC]

## 앱 화면 {#current-view}

![지갑 병합 화면](help/assets/en/wallet-merge.png)

이 이미지는 현재 Demo 병합 화면에서 캡처되었습니다.

## 개요 {#overview}

병합은 호환되는 기밀 자산 조각 두 개 이상을 하나의 출력으로 결합합니다. 출력은 동일한 `definition_id`와 기본 `serial_id`를 유지하며, 금액은 선택한 입력의 합과 같습니다. 병합은 출력 구성을 바꾸지만 자산 정의를 변경하거나 공급량을 생성하지 않습니다.

후보는 정의와 시리즈를 모두 기준으로 그룹화됩니다. 표시 기호가 같더라도 서로 다른 그룹의 조각은 결합할 수 없습니다.

## 이 화면 사용 방법 {#how-to-use-this-view}

1. 애플리케이션 헤더에서 활성 지갑과 네트워크를 확인합니다.
2. **병합**을 선택합니다.
3. 하나의 호환 그룹에서 사용 가능한 조각을 두 개 이상 선택합니다.
4. 선택한 입력 수, 총 출력 금액, 정의 및 시리즈를 확인합니다.
5. **병합 미리보기**를 선택하고 각 입력과 제안된 단일 출력을 검토합니다.
6. 권한, 수수료, 제출 및 조정을 다시 확인할 수 있는 네이티브 지갑에서만 계속합니다.

## 용어 및 제어 {#terms-and-controls}

| 용어 또는 제어 | 설명 |
| --- | --- |
| 정의 ID | 자산 유형과 정책의 변경 불가능한 식별자입니다. 선택한 모든 입력이 이를 공유해야 합니다. |
| 시리얼 ID | 기본 발행 시리즈입니다. 모든 입력과 병합된 출력은 같은 시리즈를 유지합니다. |
| 자산 ID | 하나의 구체적인 기밀 출력 식별자입니다. 호환되는 조각은 서로 다른 자산 ID를 가질 수 있습니다. |
| 호환 그룹 | 정의 ID와 시리얼 ID가 같은 사용 가능한 조각입니다. |
| 잠김 | 조각이 문맥상 표시되지만 선택할 수 없습니다. |
| 총 출력 | 별도의 네이티브 수수료 정책을 적용하기 전 선택한 입력의 정확한 합입니다. |
| 병합 미리보기 | 입력과 제안된 출력을 보여 주는 검토 전용 의도이며, 서명하거나 제출하지 않습니다. |

## 안전 및 제한 {#safety-and-limits}

- 이 인터페이스는 서로 다른 정의나 기본 시리즈를 병합하지 않습니다.
- 네이티브 지갑은 오래된 화면에 표시되었던 항목이라도 잠김, 사용됨, 동결, 소각, 삭감 또는 기타 사용 불가 상태의 입력을 거부해야 합니다.
- 조각을 병합하면 관련 입력을 더 쉽게 연관 지을 수 있습니다. 반복적이거나 뚜렷한 패턴의 작업 전에 개인정보 영향을 검토하십시오.
- JavaScript Demo는 공개 테스트 데이터를 사용하며 미리보기에서 중단됩니다. 키를 보관하거나 소유권을 증명하거나 서명을 만들거나 수수료를 부과하거나 패키지를 제출하거나 불확실한 결과를 조정하지 않습니다.
- 현재 `wallet.asset.merge_assets` helper는 호환성 표면이며 정식 원장 조정 권한을 주장하지 않습니다. 네이티브 통합은 권한 있는 지갑 트랜잭션 경로를 통해 확인을 처리해야 합니다.
