## 이 화면 사용 {#current-view}
- 64 KiB 이하의 `AssetPkgWire` JSON 패키지를 선택합니다.
- 지갑, 네트워크, 클래스, 금액, 시리얼 ID, 도메인, 상태 플래그와 소유자 바인딩을 확인합니다.
- **자산 가져오기**를 선택합니다. 네이티브 지갑이 암호화, 소유권, 재사용 및 claim 충돌을 검증합니다.

## 로컬 및 안전 동작
- `secret` 필드는 금지되며 절대 파일 경로는 저장하거나 RPC로 보내지 않습니다.
- 결과는 새 가져오기, 기존 자산, 명시적 `IMPORT_*` 사유를 구분합니다.
